Completed Degree final year project 2025 to 2026 Supervisor: Dr. Palanichamy Naveen

AI-Powered Port Scan Detection System

Feature optimization, stacked ensemble learning and explainable AI

A detection framework that classifies network flows from the CICIDS2017 dataset as benign or port scan. I compared two feature optimization methods, stacked a Random Forest base learner with an XGBoost meta-learner, and used SHAP to explain each prediction. A Streamlit dashboard lets users upload network traffic in CSV format, run either framework and see why each flow was classified as a port scan or benign.

The problem

  • Feature selection is an afterthought. Most port scan research chases accuracy and treats feature optimization as basic preprocessing, so it's unclear which methods actually help.
  • Black-box alerts. Models flag traffic as a port scan without showing why, so analysts can't verify the decision or trust the alert.
  • Overfitting. Models that score well on training data often fail on new, unseen traffic.

Objectives

  1. Implement and compare feature optimization techniques for port scan detection.
  2. Make detection decisions understandable with explainable AI (XAI).
  3. Check for overfitting by testing the models on unseen data.
  1. 01Network trafficCICIDS2017 PortScan flows, 77 features
  2. 02Feature selectionRFE (20 features) vs Moth-Flame Optimization (10)
  3. 03Stacked ensembleRandom Forest base, XGBoost meta-learner
  4. 04ExplainabilitySHAP summary and waterfall plots
  5. 05DashboardStreamlit: upload, detect, explain

Standalone Random Forest and XGBoost models trained on all 77 features were used as baselines. Each proposed framework selects features first, trains a Random Forest on them, then feeds its class probabilities together with the selected features into an XGBoost meta-learner.

  • RFE gave the best balance: 74% fewer features with no meaningful loss in accuracy.
  • MFO cut features even further to 10 and ran faster, with a small drop in accuracy.
  • The gap between training and testing accuracy stayed under 0.013% for every model, so overfitting was minimal.

Upload a CICIDS2017-format CSV, pick the RFE or MFO framework, and the dashboard validates the data, labels every flow, summarises the attack percentage and shows SHAP plots explaining individual predictions.
